# Excel 筛选助手

双击 `dist\ExcelFilterAssistant.exe`，按需要选择筛选、批量拆分、合并总表或数据分析与图表。程序在本机处理文件，不上传数据，也不修改源文件。

## 筛选步骤

1. 选择 `.xlsx` 或 `.xlsm` 源文件，再选择工作表。
2. 指定表头起止行。普通单行表头填 `1` 和 `1`；多行表头可分别指定起止行。
3. 明细起始行默认为表头结束行的下一行。若报表中有尾部汇总，可保留“遇到汇总行停止”；也可填写明细结束行精确限定范围。
4. 选择字段，扫描并勾选可选值，或手动输入要匹配的值，然后添加条件。一个字段中的多个值取“或”，不同条件之间取“且”。
5. 选择输出位置并导出。输出为新的 `.xlsx` 文件，包含表头和命中的完整明细行。

## 批量输出多个文件

**一个字段有 n 个不同值，直接生成 n 个文件：**读取表头后选择该字段，可先点“扫描可选值”查看有多少类；随后点击字段列表下方的“按此字段的每个不同值分别导出 Excel…”，选择输出父文件夹即可。例如“部门”有 7 个值，就生成 7 个 Excel 文件，每份仅含对应部门的完整明细行。此入口处理当前明细范围内的所有值，无需勾选列表，也不使用右侧已添加的单文件筛选条件。

程序提供两种批量模式，均会在所选父文件夹下新建一个独立的批次文件夹，避免覆盖旧结果：

1. **按字段自动拆分**：选择“部门”等一个字段，会按实际出现的每个部门生成一个文件；同时选择“部门”和“月份”，会按实际出现的“部门 × 月份”组合各生成一个文件。当前已添加的筛选条件会先作为共同范围。例如先筛选“部门=销售一部或销售二部”，再按“部门”拆分，就会分别输出两份。
2. **按多套条件输出**：设置第一套筛选条件并保存为一个命名任务，再修改筛选条件保存第二套任务。点击批量导出后，每套任务生成一个独立文件。适合各文件的条件不同、无法仅靠字段值组合拆分的情况。

批量结果中的每份文件都包含对应的完整明细行；若启用了会计辅助功能，各文件分别计算自己的汇总与检查。默认最多生成 200 个文件，可在批量设置中调整。文件名中的特殊字符会自动处理，重名时会自动区分。

## 多文件合并为总表

点击主界面的“合并总表…”，一次选入至少两个 `.xlsx` / `.xlsm` 文件，指定输出的 `.xlsx` 路径，再点击“开始合并”。文件可以来自“按字段批量导出”的结果，也可以是其他具有字段表头的明细表。列表顺序决定合并顺序；可以上移或下移调整。每个文件默认读取第一个工作表；若都使用相同工作表名，也可改为按名称读取。

合并按**表头名称**对齐字段，再把明细记录逐行追加。即使各文件的列顺序不同，同名字段仍会进入总表的同一列。默认使用“字段并集”，新字段追加到总表末尾，其他文件缺少的字段留空；“要求字段一致”会在字段集合不同时给出错误。表头会忽略多余空格和英文字母大小写，但不会猜测“客户”和“客户名称”等是否等价；这类字段请先统一命名。空白或重复的表头会提示修正，以免数据误入其他列。

可按需设置表头行、明细范围、遇汇总行停止、添加“来源文件”列，以及按整行业务字段去重。去重保留首次出现的记录。结果会显示扫描行数、合并行数和跳过的重复行数。若明细超出 Excel 每张工作表的 1,048,576 行上限，程序会继续写入“总表2”等后续工作表。合并时不会把源表的格式、图表、宏和公式本身复制过来；日期及数值类型、单元格数字格式和公式上次保存的计算结果会保留。

## 数据分析、计算变量与图表

先在主界面选择源文件、工作表并读取表头；如需分析某位业务员，先用现有筛选条件选择该业务员。点击“数据分析与图表…”，已有筛选条件会应用到分析范围。

新版采用 **先分组、再勾选多个指标** 的流程：

1. 在“1 分组与指标”中选择业务员、公司、部门或日期等分组字段。想让横轴显示人名，就选择“业务员”或“姓名”。
2. 在指标列表中勾选需要同时展示的字段，例如“计划回款”和“实际回款”。点击指标行可以分别配置指标名称、合计或平均等统计口径、显示格式和单位。需要计算完成率等指标时，可新增比值指标并选择分子、分母；也可以统计记录数。
3. 如需先定义新的计算变量，进入“2 定义新变量”；保存后的变量会加入指标列表，勾选后参与分析。
4. 在“3 图表设置”中选择图表类型、排序指标、排序方式和展示分组数量，再选择输出路径并生成结果。

例如按业务员分组，勾选“计划回款”“实际回款”“完成率”后，汇总表每个业务员占一行，这三个指标分别占一列。计划回款和实际回款可设为合计，完成率可设为实际回款合计 ÷ 计划回款合计。各指标独立统计，有一个指标缺值时，其他指标仍保留；无效值保持空白，结果文件中提供各指标的口径与校验信息。

计算变量通过原表列 `C1`、`C2` 等引用，编号从左到右从 1 开始；这里的 `C1` 表示原表第 1 列，并非 Excel 的 C1 单元格。新定义的变量通过 `V1`、`V2` 等引用，可以在后续变量中继续使用。例如 `C4 / C3` 生成逐行回款比例，`(C4 - C5) * 2` 生成调整金额。支持数值常数、加减乘除和括号，界面可以选择字段并插入引用。无效数值和除零结果留空，不会默认为 0。

分组指标可选金额合计、平均、记录数，以及两种比例口径：

- **合计后相除**：每个组的分子金额合计 ÷ 分母金额合计。适合比较各公司的总体回款比例。
- **逐行比值平均**：先对每条有效记录计算分子 ÷ 分母，再按组取平均。零分母或无效数值的记录不参与平均。

图表支持同时显示多个指标：

- **柱状图**：同一分组下的多个指标并排显示，用颜色和图例区分，例如每个业务员对应计划、实际两根柱子。
- **折线图**：每个指标是一条线，共用相同的分组横轴和类别顺序。
- **饼图**：每个勾选指标分别生成一张饼图，展示该指标在各分组中的构成；扇区显示名称与占比。仅支持非负金额合计或记录数，比例、平均值和负数请用柱状图或折线图。

**单位与排序**：金额和百分比自动分图；数量统计默认使用“条”。对于元、万元、笔等不同单位，请给各指标填写对应单位，程序会按单位分别作图，且不会自动换算数值。同单位的柱状图或折线图共享纵轴。按指标数值排序时可以选择排序依据；所有柱状图或折线图使用同一组横轴分类，缺失数据留空。默认图表展示前 20 个分组，可以调整为全部，完整汇总表始终保留所有分组。饼图按各自指标大小选择前几类，其余合入“其他”。

若按公司分组并筛选某位业务员，横轴显示公司名称，所用的人名和其他筛选条件会列在“分析汇总”的筛选范围中。

图表嵌入结果文件的“分析汇总”工作表，旁边保留完整分组统计表；可选择附带“分析明细”工作表，查看每条记录及新变量值。若定义了新变量，“变量定义”工作表会列出计算表达式与字段映射。若源文件内容或分析配置改变，请重新运行分析以更新结果；旧的分析文件不会自动更新。

“遇到汇总行停止”会在前四列遇到独立的“合计”“小计”“总计”“汇总”或对应英文标签时结束明细扫描。如果源表中间也有小计，请取消此选项并按需指定明细范围。

筛选支持精确匹配和包含匹配。精确匹配忽略首尾空格及英文字母大小写。空白值也可以作为条件。单元格中的日期、数值和百分比按原类型导出；公式使用源文件上次保存的计算结果。可勾选“保留格式”复制字体、填充、边框等单元格格式，处理超大表时会更慢。

## 会计辅助功能

在“会计辅助设置”中可选择：

- 金额列：对筛选后的数值求合计。
- 分组字段：按公司、部门、月份等字段统计命中行数和金额。
- 必填列：列出筛选结果中的空白单元格。
- 重复键列：按一个或多个字段检查重复记录。

启用后，结果文件会增加相应的“金额汇总”和“数据检查”工作表。汇总与检查只使用已筛选的明细行；不把源表原有的合计行当作明细。

## 文件兼容性

- 支持 `.xlsx` 和 `.xlsm` 输入，统一输出 `.xlsx`。源文件中的宏、图表、条件格式、合并单元格和原始公式不会复制到结果中；分析功能会按当前统计结果生成新的图表。
- 旧版 `.xls` 请先在 Excel 中另存为 `.xlsx`。
- 采用逐行读取和写入，适合较大的工作簿。扫描高基数字段的可选值到达上限时，可直接手动输入条件。
- 如果源文件含有公式，请先在 Excel 中计算并保存，以便结果读取最新的缓存值。

## 重新打包

在 Windows PowerShell 中运行 `./build.ps1`。脚本会在项目目录的 `.venv` 中安装依赖，并生成 `dist\ExcelFilterAssistant.exe`。
